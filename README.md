# Лендинг «Личная CRM»

Одна статичная страница. Все кнопки ведут в приложение: https://app.lena-14.ru.

Сделано на Astro и Tailwind CSS 4. Сервер и база не нужны: сборка — это папка `dist/` с готовыми файлами.

## Как запустить у себя

Нужны Node.js 22.22 или новее и pnpm.

```
pnpm install
pnpm dev
```

Страница откроется по адресу http://localhost:4321. Правки в коде видны сразу.

## Как собрать

```
pnpm build
pnpm preview
```

`pnpm build` собирает сайт в папку `dist/`, `pnpm preview` показывает собранную версию на http://localhost:4321.

Шрифты Playfair Display и Manrope Astro скачивает из Google Fonts во время сборки и кладёт в `dist/`: посетители сайта к Google не обращаются.

## Где что менять

- Тексты пунктов списков — `src/data/content.ts`
- Заголовки и остальные тексты — в файлах разделов `src/components/sections/`
- Адрес приложения — `src/config.ts`
- Цвета, шрифты, отступы, размеры текста — `src/styles/tokens.css`
- Макет — `design/`: `design/README.md` и HTML-образцы в `design/reference/`

## Выкатка

Сайт работает по адресу https://lena-14.ru.

### Как выкатить новую версию

Отправьте изменения в ветку `main` (`git push`). Дальше всё происходит само, примерно за минуту:

1. GitHub Actions собирает сайт в папку `dist/`
2. Копирует `dist/` на сервер в `/var/www/lena-14.ru` через `rsync --delete`: файлы, которых больше нет в сборке, удаляются и с сервера
3. nginx сразу отдаёт новую версию
4. GitHub проверяет, что https://lena-14.ru отвечает 200 и отдаёт ровно ту страницу, которую только что собрал

Ход выкатки виден на GitHub: репозиторий → вкладка **Actions** → workflow **Deploy**. Зелёная галочка — новая версия на сайте. Красный крестик — выкатка упала: откройте запуск и посмотрите, на каком шаге ошибка. Если упала сборка, на сайте остаётся прежняя версия.

Отдельного стенда и отката нет: если что-то сломалось — исправляем и выкатываем новую версию.

### Как это устроено

| Что | Где |
| --- | --- |
| Сценарий выкатки | `.github/workflows/deploy.yml` |
| Папка сайта на сервере | `/var/www/lena-14.ru` |
| Настройка nginx | `/etc/nginx/sites-available/lena-14.ru`, образец — `deploy/nginx/lena-14.ru.conf`. Главную браузер перепроверяет при каждом заходе, файлы из `_astro/` хранит год: их имена меняются вместе с содержимым |
| Пользователь, под которым GitHub выкатывает | `landing-deploy`. Его ключ умеет только загружать файлы в папку сайта: ни команд, ни чтения, ни других папок |

В настройках репозитория на GitHub (Settings → Secrets and variables → Actions) лежат: секрет `DEPLOY_SSH_KEY` — ключ, которым GitHub загружает файлы на сервер; переменные `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KNOWN_HOSTS` — адрес сервера, пользователь и отпечаток сервера.
